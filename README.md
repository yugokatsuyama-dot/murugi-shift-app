# シフトボード (Shift Board)

飲食店向けの月次シフト表 **表示・編集ビューア**。単一HTMLのフロントエンドのみで動作します。

- 2部門の週グリッド表示 / 個人別リスト / 印刷(A4縦)PDF出力
- NGルール(DSL)に基づく勤務不可の自動違反検知
- クリック編集・絞り込み・適性順ソート・元に戻す(Undo)
- データはサーバーに送らず、ブラウザ(localStorage)にのみ保存

## 設計方針: データはこのリポジトリに含めない

このリポジトリは **アプリの器（ガワ）のみ** を管理する公開リポジトリです。
スタッフ名・勤務割当などの実データは **一切含まれていません**。
利用者が自分の手元のJSONファイルを起動時に読み込み、その端末のブラウザ内にだけ保持します。

これにより、アプリ本体は公開ホスティング(GitHub Pages)しつつ、個人情報は公開範囲に出さない構成にしています。

## 使い方

1. ホスティングされたページを開く
2. シフトデータJSON（後述スキーマ）をドラッグ＆ドロップ、またはファイル選択で読み込む
3. 以降はこの端末で自動表示。編集→「データ」メニューから書き出して保管

操作を試したいだけなら「サンプルデータで操作を試す」（架空の名前）で体験できます。

## データJSONスキーマ（概要）

```jsonc
{
  "meta":  { "year": 2026, "month": 6, "title": "シフト表" },
  "rules": { "viewSlots": {...}, "operating": {...}, "closedWeekday": [5] },
  "staff": [ { "id": "x1", "family": "姓", "first": "名", "display": "表示名",
              "org": "murugi|ekuriya", "mgmt": false, "ng_rules": "wd火:全;all:夜" } ],
  "assignments": { "2026-06-01": { "10:30": ["x1"], "11:15": ["x2"] },
                   "2026-06-05": { "closed": true } },
  "events": [ { "name": "イベント名", "date": "6/20" } ]
}
```

NG_rules DSL: `d<日>:<枠>` / `wd<曜日,..>:<枠>` / `all:<枠>` / `ex:d<日>` / `exif:<id>`
（枠 = 全 | 昼 | 夜、`;` 区切り）

## ローカルで動かす

`index.html` をブラウザで開くだけ（ビルド不要・依存なし）。

## ライセンス / 用途

特定店舗の社内運用ツール。実データは本リポジトリ外で管理されます。
